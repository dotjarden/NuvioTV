## P3

### P3-1. Native speed: the r1 P3-7 overwrite moved from panel open to dismantle

`Screens/NativePlayerScreen.swift:596` and `:627`

The fix stops the panel open from saving when `selectedSpeed` is nil, which is right. But the new `else` branch sets `speedModel.rate = 1`, and `dismantleUIViewController` falls back to `speedModel.rate` when `selectedSpeed` is nil (`:627`). So in the same scenario (the early `selectSpeed` did not stick, critique Risk 13), opening the panel once and then leaving the player still saves 1.0 over the remembered 1.25. Before the fix the same path existed (`?? 1`); r1 called the dismantle fallback fine without spotting that. Without a panel open, `speedModel.rate` keeps the 1.25 that `NativeSpeedModel.apply` set at load, so only the open-then-leave path is affected.

Fix: make dismantle follow the same rule as the panel open (save only what the player reports):

```swift
if let selected = host.playerVC.selectedSpeed { speedModel.saveIfRemembered(rate: Double(selected.rate)) }
```

and, for the same reason, `:565` (turning Remember on) should save `Double(host.playerVC.selectedSpeed?.rate ?? Float(speedModel.rate))` rather than `?? 1`.

### P3-2. Boost value column at 90 pt may wrap "+10 dB"

`Screens/Player/PlayerAudioTab.swift:85`

The value `Text` went from 100 pt to 90 pt. At `Theme.Font.body` (29 pt, monospaced digits) "+10 dB" is about 95 pt wide, and a fixed-width `Text` with no line limit wraps to two lines rather than clipping, which would also change the row height when Boost passes +8 dB. The row is still not screenshot-verified (r1 P3-9).

Fix: add `.lineLimit(1).minimumScaleFactor(0.8)` to the value `Text` (as was done for Reset), and take one sim screenshot of the Audio tab at +10 dB in English and German before the merge.
