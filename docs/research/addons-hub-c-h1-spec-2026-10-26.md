## 1. New `NuvioTV/Screens/Addons/AddonManifestURL.swift`
`nonisolated enum AddonManifestURL` with:
- `enum Failure: Error, Equatable { case empty, unsupportedScheme(String) }`.
- `static func normalize(_ raw: String) throws(Failure) -> String` (or `-> Result<String, Failure>` if typed throws trips the toolchain; say which): trim whitespace/newlines; empty → `.empty`; `stremio://` → `https://`; a `scheme://` other than http/https/stremio (anything matching `^[A-Za-z][A-Za-z0-9+.-]*://`) → `.unsupportedScheme(scheme)`; no scheme → prefix `https://`; drop a `#fragment`; split the query off at the first `?`; trim trailing `/` from the path; append `/manifest.json` unless the path already ends with it; re-attach the query. Same outcomes as the Kotlin for every input it accepts.
- `static func isSameManifest(_ a: String, _ b: String) -> Bool`: both normalise (failures → false) and compare case-sensitively except the scheme and host, which compare lowercased.
