- House style doc comments; each finding or plan item named.

## 2. Page layout (`SourcesHubView`)
`ScrollViewReader { proxy in ScrollView(.vertical) { LazyVStack(alignment: .leading, spacing: Theme.Spacing.sectionGap) { summaryRow; actionRow; installedSection } .padding(Theme.Spacing.screen) .frame(maxWidth: .infinity, alignment: .leading) } }` with `.accessibilityIdentifier("addons_hub_root")` on the ScrollView. The toast overlays the page bottom (§5).
- **`summaryRow`**: `HStack(spacing: Theme.Spacing.lg)` of `HubCard`s, `.focusSection()`. Cards: **Add-ons** (title "Add-ons", value "\(summary.addonsInstalled) installed · \(summary.addonsOn) on", a logo strip: `HStack(spacing: Theme.Spacing.xs)` of up to five `CachedAsyncImage(string:)` 44×44, `clipShape(RoundedRectangle(cornerRadius: Theme.Radius.chip))`, from `AddonsViewModel.logoUrls(of: model.addons, limit: 5)`; action: `proxy.scrollTo("addons_hub_installed", anchor: .top)` then focus the first card (`focusedControl = "card:" + first manifestUrl` on the next runloop)). **Catalogs** ("\(catalogsOn) of \(catalogsTotal) on Home"; action: push `HomeScreenSettingsPane(model: settings)` for now — H4 swaps in `CatalogOrderView`; mark with `// H4:`). **Debrid** (value: the joined connected names + " connected", or "Not connected"; action: push `ServicesSettingsPane(trakt:simkl:debrid:confirmingTraktDisconnect:confirmingSimklDisconnect:debridDisconnectId:)` with three `@State` bindings owned by the hub). **Plugins** (only when `summary.plugins != nil`: "\(repositories) repositories · \(providers) providers"; action: push `SourcesSettingsPane(model: settings, plugins: plugins, badges: badges)`). Navigation via `NavigationLink(value:)` + `.navigationDestination(for: HubRoute.self)` where `enum HubRoute: Hashable { case catalogs, services, plugins }`, declared in `SourcesHubView`.
- **`HubCard`** (private to `SourcesHubView.swift`): `Button(action:) { VStack(alignment: .leading, spacing: Theme.Spacing.sm) { Text(title).font(Theme.Font.cardTitle); Text(value).font(Theme.Font.sectionTitle).lineLimit(2); subtitle/strip } .padding(Theme.Spacing.lg) .frame(maxWidth: .infinity, minHeight: 180, alignment: .topLeading) } .buttonStyle(.settingsRow)` (the kit's white platter on focus; text through `.rowTextColor(secondary:)`). A `ProgressView` replaces the subtitle while the value is loading (`!model.isInitialized` for Add-ons).
- **`actionRow`**: same `HubCard` style, `.focusSection()`: **Install add-on** (`plus.circle.fill`; sets `showInstall = true` → `.sheet(isPresented:) { AddonInstallSheet(model: model) }`), **Refresh all** (`arrow.clockwise`; subtitle "Updated \(relative)" from `model.lastRefreshedAt` through `RelativeDateTimeFormatter` (`.named`), "Not refreshed yet" when nil; a `ProgressView` in the title row while `model.isRefreshingAny`; action `model.refreshAll()`), **Manage from phone** only when `DebugConfig.showsPhoneManagement` (add `static let showsPhoneManagement = false` to `DebugConfig`; H6 flips it; the card then does nothing but show "Coming in a later beta").
- **`installedSection`**: `VStack(alignment: .leading, spacing: Theme.Spacing.md)` with `.id("addons_hub_installed")`: title row `HStack { Text("Installed add-ons").font(Theme.Font.screenTitle); if !model.isInitialized { ProgressView() } }` (`addons_hub_installed_title`); when initialized and empty: `Text("No add-ons installed. Install one to get started.")` secondary (`addons_hub_empty`); else `ForEach(Array(model.addons.enumerated()), id: \.element.manifestUrl) { index, addon in AddonCardView(...) }`. When `model.isReadOnly`: a one-line note above the cards, "This profile uses the primary profile's add-ons. Manage them there." (`addons_hub_readonly`), and every card control disabled.

## 3. `AddonCardView`
Inputs: `addon: ManagedAddon`, `index: Int`, `count: Int`, `isReadOnly: Bool`, `focus: FocusState<String?>.Binding`, callbacks `onOpen`, `onToggle`, `onMoveUp`, `onMoveDown`, `onRemove`.
Container: `HStack(spacing: Theme.Spacing.lg) { nameArea; Spacer(minLength: Theme.Spacing.md); controls } .padding(Theme.Spacing.lg) .background(Theme.Palette.surface, in: RoundedRectangle(cornerRadius: Theme.Radius.card, style: .continuous)) .focusSection()` — one focus section so Left/Right stay inside the card and Up/Down move between cards.
- **Name area** = `Button(action: onOpen)` with `.buttonStyle(.settingsRow)`, `.focused(focus, equals: "card:\(addon.manifestUrl)")`, identifier `addons_hub_card_\(index)`: 44×44 logo (`CachedAsyncImage(string: addon.manifest?.logoUrl)` with a `puzzlepiece.extension` glyph fallback — use the `fallback`/failure view the component offers; say which), then `VStack(alignment: .leading, spacing: Theme.Spacing.xxs)`: `AddonsViewModel.displayTitle(addon)` (`sectionTitle`, 1 line); "v\(version) · " + `resourceLabels(of:)` joined by " · " (`meta`; "Loading…" when no manifest); `host(of: addon.manifestUrl)` (`caption`, secondary); "Catalogs: \(manifest.catalogs.count)" (`caption`) when a manifest exists. Then the **status pill**: `Text` of `status(of:)` → "Active" / "Disabled" / "Refreshing" (with a small `ProgressView`) / "Unavailable", `font(Theme.Font.caption)`, `padding(.horizontal, Theme.Spacing.sm).padding(.vertical, Theme.Spacing.xxs)`, `background(Capsule().fill(...))`: `Theme.Palette.error.opacity(0.18)` for unavailable, `Theme.Palette.surfaceElevated` otherwise; identifier `addons_hub_status_\(index)`, accessibility label = the status word.
- **Controls** = `HStack(spacing: Theme.Spacing.sm)` of four `Button`s with `.buttonStyle(.chip)`: **On/Off** `SettingsSwitchGlyph(isOn: addon.enabled)` (`addons_hub_card_\(index)_toggle`, accessibility label "On" / "Off", value "enabled"/"disabled"), **Up** `Image(systemName: "chevron.up")` (`_up`, disabled when `index == 0`), **Down** `chevron.down` (`_down`, disabled when `index == count - 1`), **Remove** `trash` tinted `Theme.Palette.error` (`_remove`, label "Remove"). Each `.focused(focus, equals: "<kind>:\(addon.manifestUrl)")` with kinds `toggle`, `up`, `down`, `remove`. All four `.disabled(isReadOnly)` in addition.
- Glyph font `Theme.Font.body`; the chip style supplies the platter.

## 4. Reorder with focus kept (`SourcesHubView`)
`@FocusState private var focusedControl: String?`. `onMoveUp`/`onMoveDown` call `model.move(manifestUrl:by:)` then `DispatchQueue.main.async { focusedControl = "up:\(url)" / "down:\(url)" }` (the same control on the moved card; when the move lands at an end the control is disabled, so target `"card:\(url)"` instead: compute from the new index = index ± 1 against `count`). Toggle keeps its own focus naturally. After a Remove confirm, focus `"card:"` of the card that took the removed card's index (or the previous one at the end, or the Install action card when the list is empty).

## 5. Toast and sheets
- Toast: `@State private var toast: String?` + `private func showToast(_:)` exactly like `StreamPickerView.showToast` (2.5 s, replaced by a newer one), the view from `StreamPickerView.swift:363-372` (`Theme.Surface.overlay` capsule, bottom-aligned, `.transition(.move(edge: .bottom).combined(with: .opacity))`), identifier `addons_hub_toast`. Messages: "Refreshing \(n) add-ons…" on Refresh all (n = enabled count; "Nothing to refresh." when 0), the `model.lastRefreshOutcome` on change: "Refreshed \(succeeded) add-ons." / "Refreshed \(succeeded), \(failed) failed."; `model.statusMessage` on change (install results); "Removed \(name)." after a remove.
- `AddonDetailSheet` (`.sheet(item: $detailTarget)` where `struct DetailTarget: Identifiable { let addon: ManagedAddon; var id: String { addon.manifestUrl } }`): `ScrollView { VStack(alignment: .leading, spacing: Theme.Spacing.lg) }` padded `Theme.Spacing.screen`, identifier `addons_hub_detail_sheet`: title (`screenTitle`), description (`body`, `lineLimit(6)`), "Version \(version) · \(types joined ", ")" (`meta`), resource labels row (`meta`), "Catalogs" list of names (`caption`, up to 12 then "+N more"), the manifest location as `scheme://host/path` WITHOUT the query plus "(key hidden)" when the URL has a query (`caption`, secondary; identifier `addons_hub_detail_location`), then a button row `.focusSection()`: **Refresh** (`model.refresh(manifestUrl:)`, `addons_hub_detail_refresh`), **Remove** (opens the same confirm alert, `addons_hub_detail_remove`), **Configure** only when `addon.manifest?.behaviorHints.configurable == true` (`addons_hub_detail_configure`): toggles a section below with the QR (`QRCode.image(for: configureUrl)` in an `Image(uiImage:)` 320×320, `.interpolation(.none)`) and the configure URL text (`caption`) — `configureUrl` = the manifest URL with a trailing `/manifest.json` (before any query) replaced by `/configure`, query kept. Buttons `.buttonStyle(.borderedProminent)` for Refresh, `.bordered` for the others (the Cinematic D9 look).
- `AddonInstallSheet(model:)`: the verbatim move of today's `installSection` (field, Install, DEBUG quick install, spinner, status) in a `VStack` padded `Theme.Spacing.screen`, title "Install add-on" (`screenTitle`), identifiers `addons_hub_install_field`, `addons_hub_install_button`, `addons_hub_install_status`. On `model.statusMessage` starting with "Installed" the sheet dismisses itself after 1.2 s (H3 refines).
